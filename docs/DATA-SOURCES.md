# Data Sources & Providers — HEATSHIELD AI

## 1. Meteorology & Weather Stream
- **Provider:** Open-Meteo Free Meteorological API (`https://open-meteo.com`)
- **Cost:** ₹0 / Free tier (No API key required)
- **Parameters:** Dry bulb air temperature, relative humidity, apparent temperature, surface pressure, wind speed at 10m height, 48h hourly forecasts.

## 2. Geocoding & Reverse Geocoding
- **Provider:** Open-Meteo Geocoding API (`https://geocoding-api.open-meteo.com`)
- **Parameters:** City name, administrative region, country, latitude, longitude.

## 3. Spatial Map Tiles
- **Provider:** OpenStreetMap Foundation (`https://www.openstreetmap.org`)
- **Render Engine:** Leaflet JS (`leaflet.js`)
